# 嵌入式代码评审清单

## 架构
- [ ] 依赖方向正确。
- [ ] APP/Service 无未解释的 HAL 直接调用。
- [ ] Protocol 与 UI/业务分离。
- [ ] `main.c` / `freertos.c` 足够薄。

## RTOS
- [ ] 每个 Task 都有独立并发理由。
- [ ] 优先级和栈大小有依据。
- [ ] ISR 无阻塞/重业务。
- [ ] Queue 元素大小和深度合理。
- [ ] Mutex 所有权清晰。

## 可靠性
- [ ] 外部等待有 Timeout。
- [ ] 外设离线/降级策略明确。
- [ ] Watchdog 验证系统进展而非无条件喂狗。
- [ ] 所有缓冲区检查长度。
