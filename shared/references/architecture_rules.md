# 架构规则

## 层级职责矩阵
| 关注点 | L1 Vendor | L2 BSP Driver | L3 Device/Protocol/BSP Service | L4 Service | L5 APP |
|---|---:|---:|---:|---:|---:|
| HAL 句柄 | 是 | 是 | 尽量否 | 否 | 否 |
| GPIO/外设实例 | 初始化 | 是 | 通过资源ID | 否 | 否 |
| DMA 回调 | 胶水 | 是 | 通知/搬运 | 否 | 否 |
| 协议解析 | 否 | 否 | 是 | 否 | 否 |
| 具体器件 | 否 | 否 | 是 | 通过接口 | 否 |
| 产品状态机 | 否 | 否 | 否 | 可辅助 | 是 |
| Task 创建 | 否 | 否 | 否 | 否 | RTOS编排 |

规则：上层可依赖下层，下层禁止 include 上层。APP/Service 中出现 `HAL_*` 必须有明确理由并接受评审。
